# 原 Adaptive RAVEN 与三个基线的同批对照

> 最新当前配置开发结果（2026-10-10）：[112请求完结分析](RESULT-RAVEN-DOMINANCE-2026-10-10.md)。同批8训练题×2seed中，原B12/16、2.6249TPS、460.26秒；deep4_balanced16/16、2.6868TPS、437.31秒，已在点结果上改善原B。此数据与下表旧100题不同，不能跨表比较百分比。下表保留最初原方法历史数据。

整理日期：2026-10-09（UTC+8）。实验日期：2026-09-30。状态：400 条历史记录 CPU 复核通过；本次没有新增 GPU/HTTP 调用。

## 版本和测试条件

这里的“原版本”是最初设备适配跑通后的 **Adaptive RAVEN 组**，保留当时原方法配置，尚未加入后续 D4 Anchor、概率上限、target_odds 等方法优化。运行环境仍是本机适配环境，不能标成未做任何软件/量化适配的上游 BF16 实验。

采用规模最大的完整同批基线测试：GSM8K test 固定 100 题、基础生成 seed42、temperature0.6、输出上限2048、上下文4096、KV1GiB，FastMTP FP4 Target / BF16 MTP；四方法的题目/答案/生成种子一致。

## 原方法与基线结果

| 方法 | 原评分正确率 ↑ | E2E token/s ↑ | 平均整题耗时/s ↓ | 平均接收长度 MAL ↑ |
| --- | ---: | ---: | ---: | ---: |
| Native | **88/100（88.00%）** | 2.6591 | 250.69 | 2.9113 |
| Cactus | 83/100（83.00%） | **2.9876** | **203.17** | 3.2722 |
| SpecCascade | **88/100（88.00%）** | 2.7989 | 220.23 | 3.0678 |
| **原 Adaptive RAVEN** | 86/100（86.00%） | 2.8278 | 235.04 | **3.4759** |

原评分沿用仓库数字答案解析；截断仅作诊断，不单独否决。吞吐为总输出 token / 总客户端耗时，整题均值为总客户端耗时 / 100。

MAL 按 `1 + 总接受草稿 token / 总验证轮数` 统计。原方法 MAL=3.4759，对应平均每轮接受约2.4759个草稿token；该指标按轮数加权，不等同于每题平均值或候选接受率。

## 分析

- **对 Native：**吞吐 +6.34%、平均整题耗时 −6.24%，但少判对2题。
- **对 Cactus：**多判对3题，但吞吐 −5.35%、平均整题耗时 +15.69%。
- **对 SpecCascade：**吞吐 +1.03%，但少判对2题、平均整题耗时 +6.73%。
- **原方法的接收长度高于三个基线，尚未转化为同时满足正确率不下降、吞吐更高、整题更快的收益。**
